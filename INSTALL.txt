SMART ENTITY TIMER CARD 0.2.2 — INSTALLATION / UPDATE

REQUIREMENT
Smart Entity Timer integration 0.1.3 or newer (card_api_version: 2).

RECOMMENDED: HACS

1. Open HACS.
2. Search for "Smart Entity Timer Card".
3. Download/install it.
4. HACS should register the dashboard resource automatically.
5. Add the card from the Home Assistant dashboard editor.

The HACS installation path and automatic resource registration have been validated on a clean Home Assistant OS installation.

MANUAL INSTALLATION

1. Copy dist/smart-entity-timer-card.js to:
   /config/www/smart-entity-timer-card/smart-entity-timer-card.js
2. In Settings > Dashboards > Resources, use:
   /local/smart-entity-timer-card/smart-entity-timer-card.js?v=0.2.2
3. If upgrading, change the old ?v=... value to ?v=0.2.2.
4. Hard-refresh the browser (Ctrl+F5) or fully close/reopen the mobile app.

Existing 0.1.1 card configurations do not need to be recreated.
All 0.2.x personalization options are optional.
