SMART ENTITY TIMER CARD 0.3.0 — INSTALLATION / UPDATE

REQUIREMENT
Smart Entity Timer integration with card_api_version: 2.
Smart Entity Timer 0.3.0 is recommended.

RECOMMENDED — HACS

1. Open HACS.
2. Search for Smart Entity Timer Card.
3. Install or update to version 0.3.0.
4. HACS should create/manage the dashboard resource automatically.
5. Reload the Home Assistant frontend or fully close/reopen the mobile app.

MANUAL INSTALLATION / UPDATE

1. Copy dist/smart-entity-timer-card.js to:
   /config/www/smart-entity-timer-card/smart-entity-timer-card.js
2. In Settings > Dashboards > Resources, use:
   /local/smart-entity-timer-card/smart-entity-timer-card.js?v=0.3.0
3. If upgrading, change the old ?v=... value to ?v=0.3.0.
4. Hard-refresh the browser or fully close/reopen the Home Assistant mobile app.

Existing 0.2.2 card configurations do not need to be recreated.
Card API remains version 2.
